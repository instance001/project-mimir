# Project Mímir Public Specification Release

## Release Marker

This repository marks the initial public release of the Project Mímir research
specifications.

The release preserves a proposed double-blind epistemic-cartography programme
and its integration hypothesis with Project Leviathan before any experimental
platform or production implementation is built.

## Repository Scope

This release is document-only. It does not include source code, model weights,
datasets, participant records, hosted services, executable applications, or
validated claims about human or model cognition.

Future implementations may cite, derive from, or test these specifications, but
they should preserve the stated experimental safeguards and live in separate
repositories unless this repository's scope is explicitly revised.
